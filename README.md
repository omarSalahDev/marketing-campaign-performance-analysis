# 🔐 Segmentation Methodology

### Avoiding Target Leakage

</div>

The segmentation model intentionally **did not use campaign response variables** as clustering inputs.

Excluded from clustering:

- `Response`
- `AcceptedCmp1`
- `AcceptedCmp2`
- `AcceptedCmp3`
- `AcceptedCmp4`
- `AcceptedCmp5`

These variables were only used **after segmentation** to evaluate campaign responsiveness.

<br>

<div align="center">

> 🧠 **Why?** Using campaign response to create the segments would make the later comparison circular and could introduce target leakage.

</div>
